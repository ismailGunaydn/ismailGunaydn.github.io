## 🗂️ Repository Structure

```
ismailGunaydn.github.io/
├── index.html      # Hub landing page (deployed to GitHub Pages)
├── sitemap.html    # Human-readable sitemap of every brand and Pages site
└── README.md       # You are here
```

The repository intentionally stays minimal — it is a static, dependency-free landing page optimized for fast load times and clean SEO signals (canonical tags, structured data, sitemap-ready links).

## 🚢 Deployment

This repository is published automatically via **GitHub Pages** from the `main` branch.

- Source: `main` branch / root
- URL: <https://ismailgunaydn.github.io/>
- Custom domain: redirected through `ismailgunaydin.com`

Any push to `main` triggers a re-deploy within a few minutes.
